# Diagram specifications

The images in this folder are reference renderings of the "Internet Banking System" (Big Bank plc) example from the [C4 model](https://c4model.com/) website by Simon Brown.
They are used here as target specifications for the diagrams of the Sirius Web C4 modeler.
